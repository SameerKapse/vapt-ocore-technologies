# VAPT Project — Ocore Technologies LLP

## Overview
Repository for documenting assessment scope, methodology, artifacts, and reporting deliverables for the Vulnerability Assessment and Penetration Testing (VAPT) audit.

## Scope
- **Web / Software (sw/):** Web application interfaces, APIs, and network endpoints.
- **Mobile Application (apk/):** Android client testing (OWASP MASVS / MSTG guidelines).
- **Deliverables (report/):** Executive summary, technical vulnerability findings, and remediation advisory.

## Directory Mapping
- `sw/` — Scope lists, test notes, and software audit logs.
- `apk/` — APK reverse engineering notes, static analysis records, and dynamic proxy logs.
- `report/` — Assessment report drafts, final client deliverables, and evidence screenshots.
